# 📊 CPR Training System — Dashboard IoT

แดชบอร์ดสำหรับแสดงผลข้อมูลการฝึก CPR จากอุปกรณ์ IoT (หุ่นฝึก CPR) แบบ Real-time พร้อมกราฟ สถิติ และการส่งออกข้อมูล

🔗 **Live Demo:** [kittiphongkubkub.github.io/Dashboard-IOT](https://kittiphongkubkub.github.io/Dashboard-IOT)

---

## ✨ ฟีเจอร์หลัก

| ฟีเจอร์ | รายละเอียด |
|--------|-----------|
| 📈 กราฟแนวโน้มคะแนน | แสดงคะแนนของผู้ทดสอบแต่ละคน (Chart.js) |
| 🥧 สถิติผล Pass/Fail | สัดส่วนผู้รอดและไม่รอด (Pie Chart) |
| 📋 ตารางข้อมูลทั้งหมด | ดู ID, ชื่อ, เวลา, แรงกด, จังหวะ, คะแนน, สถานะ |
| 🔍 ค้นหาและกรองข้อมูล | กรองตามสถานะ, ค้นหาชื่อ, เรียงลำดับ |
| 📤 ส่งออก CSV | Export ข้อมูลออกเป็นไฟล์ CSV |
| ➕ เริ่มการทดสอบใหม่ | บันทึกข้อมูลผู้ทดสอบใหม่ผ่าน Modal |

## 📁 โครงสร้างโปรเจก

```
Dashboard-IOT-main/
├── index.html          # หน้าแดชบอร์ดหลัก
├── style.css           # สไตล์ UI
├── script.js           # Logic หลัก (กราฟ, ตาราง, ฟิลเตอร์, CSV export)
├── scenario.html       # หน้าสถานการณ์ฝึก
├── training.html       # หน้าโหมดฝึก CPR
├── training.js         # JavaScript สำหรับโหมดฝึก
└── assets/             # รูปภาพและทรัพยากร
```

## 🛠️ Tech Stack

- **HTML5 / CSS3** — UI และ Layout
- **Vanilla JavaScript** — Logic หลักทั้งหมด
- **[Chart.js](https://www.chartjs.org/)** — กราฟ Line และ Pie Chart
- **Noto Sans Thai** (Google Fonts) — ฟอนต์ภาษาไทย

## 📊 ข้อมูลที่แสดง

| คอลัมน์ | ความหมาย |
|--------|---------|
| ID | รหัสการทดสอบ |
| วันที่-เวลา | เวลาที่ทำการทดสอบ |
| ชื่อผู้ทดสอบ | ชื่อ-นามสกุล |
| เวลาที่ใช้ฝึก | ระยะเวลาการฝึก (2 หรือ 4 นาที) |
| เฉลี่ยแรงกด (N) | แรงกดเฉลี่ยจากเซนเซอร์ IoT |
| จังหวะ (ครั้ง/นาที) | ความเร็วการกดหน้าอก |
| คะแนน | คะแนนรวม (เต็ม 100) |
| สถานะ | รอด / ไม่รอด |

## 🚀 วิธีใช้งาน

1. Clone หรือดาวน์โหลดโปรเจก
2. เปิดไฟล์ `index.html` ในเบราว์เซอร์
3. กด **"เริ่มการทดสอบใหม่"** เพื่อเพิ่มข้อมูลผู้ทดสอบ
4. เลือกสถานการณ์ (จมน้ำ / หมดสติ) และระดับ (2 หรือ 4 นาที)

## 🔧 การเชื่อมต่อ IoT

แดชบอร์ดนี้ออกแบบมาให้รับข้อมูลจากหุ่นฝึก CPR ที่ติดตั้งเซนเซอร์วัดแรงกดและจังหวะ สามารถต่อยอดเชื่อมต่อกับ **MQTT / REST API** เพื่อรับข้อมูล Real-time ได้
